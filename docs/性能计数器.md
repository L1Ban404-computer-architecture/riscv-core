# 性能计数器

`performance_stats` 只观察流水线握手、各级 payload 已有的原始指令和核心侧 CoreBus 的
monitor interface。计数不参与功能控制；复位清零，64 位累计值自然回绕。
mini-soc 与 ysyx-soc 从同一口径的快照生成 `*-perf.log`，终端仍只打印 IPC。

## 指令与局部阻塞

类别数组顺序固定为 compute、load、store、branch、jump、system、other，
对应 `riscv_core_pkg::perf_class_e`。分类完全位于 `performance_stats`，功能
流水级和 decoder 不生成或传递性能类别字段，也不提供专用分类端口。
观察器统一读取各级原始指令的 `instr[6:0]`，按主 opcode 分组：

- OP、OP-IMM、LUI、AUIPC → compute。
- LOAD、STORE → load、store。
- BRANCH → branch；JAL、JALR → jump。
- SYSTEM、MISC-MEM → system（含 CSR、ECALL、EBREAK、MRET、FENCE/FENCE.I）。
- 未知 opcode、有效的 `EXC_INST_ACCESS_FAULT` 取指访问异常 → other。

不额外校验 funct3/funct7 等子编码。未支持的 M 扩展 OP 编码归 compute，非法
LOAD 子编码归 load；other 不代表所有非法指令。执行和数据访问异常不覆盖
opcode 分类，取指异常仅在 exception.valid 有效时覆盖分类。

ID、EX、MEM、WB 分别观察 IF/ID、ID/EX、EX/MEM、MEM/WB 的原始指令和异常；
退休分类使用 MEM/WB。同一组合分类函数供全部统计点复用。
局部阻塞为“入口 valid 且不 ready，同时出口没有阻塞”，WB 仅看入口；
redirect/flush 沿用原有排除条件。不同阶段局部阻塞可能重叠，不可直接相加
解释为 CPI 损失。当前 WB 无背压，因此 WB 阻塞为零是正常结果。

IF 还没有分类，只累计后端愿意接收但 IF/ID 无有效事务的周期；临时单指令
模式主动停止取指的后端执行周期不计入。没有边界 fire 或统一 stall 计数器。

退休数量沿用调试提交握手口径，包含异常，并非架构 `minstret`。
总体平均局部阻塞 = 各类别阻塞之和 / 总退休数量；分类平均局部阻塞 =
该类阻塞 / 该类退休数量。不进行错误路径的单独归因或回滚。

## CoreBus 访存统计

imem/dmem 在核心侧观察，imem 包含最终丢弃的取指，dmem 包含 MMIO。
`memory_performance_stats` 使用 `core_bus_if.monitor` 和性能模块共享的周期
计数器，只采集握手事件，不修改 ready/valid，不限制功能通路发出请求。

每个端口仅保留六个 64 位值：请求数量、请求时刻之和、最后请求时刻、响应
数量、响应时刻之和、请求背压周期数。请求侧和响应侧各自独立更新，不读取
对方状态；没有队列、指针、在途状态机或独立的时钟计数器。

仿真端以 R/C 表示请求/响应数，Q/S 表示请求/响应时刻之和，L 表示最后请求
时刻，计算：

```text
已完成事务总延迟 = S - Q + (R - C == 1 ? L : 0)
平均延迟         = 已完成事务总延迟 / C
请求背压占比     = 请求背压周期数 / 总周期数 × 100%
```

减法和未完成请求修正先在无符号 64 位整数域内完成，再转换为浮点数求均值。
这样避免大时间戳的浮点相减误差，并保留累计值自然回绕的语义。延迟从请求
握手到响应握手：同拍 0、下一拍 1，包含响应背压；错误响应也计为完成。
已接受事务不因 redirect 被清除，停止时未完成请求不污染平均延迟。

本版本要求每个端口最多一个请求在途，只用观察侧断言检查，不向功能通路
添加限制。旧响应完成与新请求接受可以同拍发生。功能内存模块自己的队列
参数保留，性能观察器不再配置队列深度或报告并发指标。

## 日志布局

首行只显示模型名、IPC 和总体 IF 局部阻塞均值。流水线表把总体 `all` 和分类
合并，列为 share、ID、EX、MEM、WB；省略退休数量为零的类别，阶段列固定。
总体按全部退休指令归一，类别按本类退休指令归一，均值单位为 cyc/inst。
访存表仅有 imem/dmem 两行，报告 latency(cyc) 和 req stall(%)。

数字使用四位有效数字，零显示 `0`，零分母显示 `-`。日志不再展开 CPI、原始
计数器、吞吐率、在途/忙碌信息或 definitions。终端保留 IPC 输出，日志路径
仍为 `*-perf.log`。
